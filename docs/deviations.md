# Deviations from the registered design

Departures from `docs/design.md` after the OSF registration is filed, with the date
and the reason (design document, Section 15.2). Section numbers refer to that
document. The log opens when the registration is filed. Decisions made before filing
are in `docs/decision_log.md`.

| Date | Section | Description | Reason |
|---|---|---|---|
| 2026-11-20 | 4.3 (report-card coverage table) | The full 204-row state-year coverage table was not attached to the registration; only the 52-row state summary (`data/reference/hs_reportcard_coverage.csv`) was. The full table is deposited with the report-card data deposit instead, unchanged from the version completed on 2026-11-18. | The registration form limits each question to five files and the full table was left out when the attachments were assembled. Its content was fixed before filing and is not altered. |
| 2026-11-20 | 4.3 (coverage exclusion) | Montana, 2022-2025, is excluded from the high school report-card outcome. | The GEMS dashboard exports one location and one student group at a time and does not allow export of the underlying data, so no file crosses district with race. Montana is excluded from every event set, so no estimate changes. |
| 2026-11-20 | 4.3 (coverage exclusion) | Mississippi, 2022-2025, is excluded from the high school report-card outcome. | The district file by race (gap analysis report) pools all tested grades, and the Algebra I and English II file reports all students only. No file crosses race with the tested course. Mississippi's SEDA and graduation outcomes are not affected. |
| 2026-11-20 | 4.3 (coverage exclusion) | Maine, 2022, is excluded from the high school report-card outcome. | The published workbook begins with 2022-23 for high school, and the ESSA dashboard shows one school administrative unit at a time. |
| 2026-11-20 | 4.3 (coverage exclusion) | Alaska, 2022-2025, is excluded from the high school report-card outcome. | The district files carry one row per subject and student group with no grade field, so grade 9 results by race cannot be separated from the other tested grades. |
| 2026-11-20 | 4.3 (coverage exclusion) | Iowa, 2022-2025, is excluded from the high school report-card outcome. | The district proficiency workbook reports each district by grade for all students only and carries no race subgroup. |
| 2026-11-20 | 4.3 (coverage exclusion) | Michigan, 2022-2025, is excluded from the high school report-card outcome. | The SAT files by race cross race only with sex, English learner status or disability, with percentages and no counts, so no race-alone rows can be formed. The High School Assessments file carries no SAT rows. |
| 2026-11-20 | 4.3 (coverage exclusion) | Arkansas, 2022-2025, is excluded from the high school report-card outcome. | The 2022 ACT Aspire workbook reports districts for all students only, with race on the state sheet only. The My School Info district export was not acquired for any year because Arkansas is excluded from every event set, so no estimate uses its report-card files. |
| 2026-11-20 | 4.1 (end year 2019 copy) | For end year 2019 the federal assessment and participation files are read from the Education Data Center archive copy, which covers 50 jurisdictions; Vermont 2019 is a missing state-year. When no copy covers the 50 states and DC, the copy covering the most jurisdictions is read. The ED Data Library loader now reads only the full data member of each zip, not the data notes or the split part files. | Found in the rehearsal. ED's 2019 release holds 937,217 of the 1,391,420 rows its README lists and has no rows after North Dakota (35 jurisdictions), and the archive copy has no Vermont rows, so neither copy meets the coverage rule. |
