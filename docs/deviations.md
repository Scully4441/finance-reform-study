# Deviations from the registered design

Departures from `docs/design.md` after the OSF registration is filed, with the date
and the reason (design document, Section 15.2). Section numbers refer to that
document. The log opens when the registration is filed. Decisions made before filing
are in `docs/decision_log.md`.

| Date | Section | Description | Reason |
|---|---|---|---|
| 2026-11-20 | 4.3 (report-card coverage table) | The full 204-row state-year coverage table was not attached to the registration; only the 52-row state summary (`data/reference/hs_reportcard_coverage.csv`) was. The full table is deposited with the report-card data deposit instead, unchanged from the version completed on 2026-11-18. | The registration form limits each question to five files and the full table was left out when the attachments were assembled. Its content was fixed before filing and is not altered. |
| 2026-11-20 | 4.3 (coverage exclusion) | Montana, 2022-2025, is excluded from the high school report-card outcome. | The GEMS dashboard exports one location and one student group at a time and does not allow export of the underlying data, so no file crosses district with race. Montana is excluded from every event set, so no estimate changes. |
| 2026-11-20 | 4.3 (coverage exclusion) | Mississippi, 2022-2025, is excluded from the high school report-card outcome. | The district file by race (gap analysis report) pools all tested grades, and the Algebra I and English II file reports all students only. No file crosses race with the tested course. Mississippi's SEDA and graduation outcomes are not affected. |
| 2026-11-20 | 4.3 (coverage exclusion) | Maine, 2022, is excluded from the high school report-card outcome. | The published workbook begins with 2022-23 for high school, and the ESSA dashboard shows one school administrative unit at a time. |
